## Recovery Incident

**What happened**: Python regex batch script (`_fix_ws.py`) corrupted stdlib.cpp — duplicated ws_ns 3x, sql_ns 4x, causing 100+ compile errors and C1075 fatal brace mismatch.

**Recovery steps**:
1. Found `stdlib.cpp.tmp` (312KB, 7144 lines, 2026-05-05 13:28 timestamp)
2. Restored both `.tmp` files via batch copy
3. Noted ~4000 lines of later-afternoon stdlib expansion missing (registerIterator, registerThreading, registerCharconv, etc.)
4. Commented out 10 missing `registerXxx(vm)` calls from `registerAll()`
5. Re-added WS and SQLite namespaces + registrations cleanly (single Python script)
6. Build succeeded, all 91 tests pass

**Lost**: ~4000 lines of iterator/threading/format/functional/charconv/memory/span modules (implementations exist in git history context but not in current source). Can be reconstructed.

## Anti-Patterns Identified (User Feedback)

1. **Python batch regex replacement on source code** → frequent corruption. Future: use `edit` tool for precise single-line changes, or write new code in separate files and `#include` them.
2. **No regular git commits** → repo had only 696-line initial commit. Now: hourly auto-backup cron + explicit commits at milestones.
