# 🚀 CP 语言 — 纯中文编程语言

CP 语言是一款支持**原生中文语法**的编程语言。
所有关键字、标准库函数都有完整的中文别名，可以使用纯中文编写程序。

## 快速开始

```bash
# 编译（需要 Visual Studio 2022）
build_msvc.bat

# 运行示例
cd examples
cplang.exe -c 图书管理.cp
```

## 中文示例

```cp
// 你好，世界！
打印("你好，世界！");

// 变量和计算
变量 半径 = 10;
变量 面积 = 圆周率() * 半径 * 半径;
打印("面积: " + 转字符串(面积));

// 条件和循环
变量 i = 0;
当 (i < 10) {
    如果 (i % 2 == 0) {
        打印(转字符串(i) + " 是偶数");
    }
    i = i + 1;
}

// 函数
函数 斐波那契(n) {
    如果 (n <= 1) { 返回 n; }
    返回 斐波那契(n - 1) + 斐波那契(n - 2);
}
打印(斐波那契(10));
```

## 主要特性

- ✅ **纯中文语法** — 关键字、函数名、变量名均支持中文
- ✅ **中文标准库** — 400+ 函数均有中文别名
- ✅ **双执行引擎** — 字节码 VM + JIT（LLVM）
- ✅ **中文错误信息** — 编译器错误、运行时异常均为中文
- ✅ **图形支持** — Raylib + ImGui 中文绑定
- ✅ **网络支持** — TCP/HTTP/WebSocket
- ✅ **数据库支持** — SQLite/MySQL/PostgreSQL/Redis

## 构建要求

- Windows 10+
- Visual Studio 2022 (MSVC v143)
- 可选: LLVM 18+ (启用 JIT)

## 目录结构

```
src/           — 编译器源码
  vm/          — 虚拟机（vm_exec.cpp 中文版）
  lexer/       — 词法分析器
  parser/      — 语法分析器
  semantic/    — 语义分析器
  codegen/     — 代码生成器
  stdlib/      — 标准库（中文别名注册）
  exception/   — 异常处理（中文错误）
  debug/       — 调试器
examples/      — 示例程序（全部中文 API）
build/         — 编译输出
```
