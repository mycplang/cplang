## 🚀 组织介绍

**CP语言** 是一款支持**原生中文语法**的编程语言，让中文开发者可以用母语编写程序。

### 核心特性

- **纯中文语法** — 关键字、函数名、变量名均支持中文
- **双引擎架构** — DevEngine（字节码 VM + JIT 加速）+ AOTEngine（LLVM 原生编译）
- **渐进类型系统** — 动态起步 + 类型标注获 JIT 加速
- **丰富标准库** — 800+ 函数，775+ 中文别名
- **图形支持** — Raylib + ImGui 中文绑定
- **网络与数据库** — TCP/HTTP/WebSocket + SQLite/MySQL/Redis
- **FFI 支持** — 调用任意 C 动态库，支持回调

### 愿景

让编程语言不再受限于英语，降低中文用户进入编程世界的门槛，让每个人都能用自己的语言创造软件。
