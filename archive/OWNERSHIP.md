# CP 语言所有权与借用检查

> **三层内存模型**：GC 自动管理（默认）→ 所有权系统（进阶）→ 不安全手动（高级）

## 设计哲学

CP 语言采用**三层心智模型**，不同于 Rust 的"全员强制所有权"：

| 层级 | 适用人群 | 内存模式 | 安全保证 | 学习成本 |
|------|---------|---------|---------|---------|
| L1 | 初学者 | GC 自动管理 | 完全安全 | 低 |
| L2 | 进阶用户 | 所有权+借用 | 编译时安全 | 中 |
| L3 | 系统程序员 | 不安全块+手动 | 开发者负责 | 高 |

---

## 1. GC 模式（默认）

所有变量默认由 **三色标记 GC** 管理，无需手动释放：

```cplang
// GC 自动管理所有堆分配
变量 data = [1, 2, 3, 4, 5]
变量 name = "你好，世界！"
变量 map = {"key": "value"}

// 函数返回引用，GC 跟踪生命周期
函数 创建数组(): 整数[] {
    返回 [10, 20, 30]
}

变量 arr = 创建数组()  // GC 确保 arr 可用
```

### GC 特性

- **三色标记-清除**算法（白→灰→黑）
- **增量式**：分步骤执行，减少暂停时间
- **循环引用检测**：处理自引用和循环引用
- **触发条件**：分配量达到阈值（默认 1MB）
- **手动触发**：调用 GC 相关函数

## 2. 所有权系统

当需要更精细的内存控制时，启用所有权模式。

### 2.1 所有权规则

```
1. 每个值有且只有一个所有者
2. 所有权通过赋值转移
3. 所有权在函数参数传递时移动
4. 所有者超出作用域时值被释放
```

```cplang
// 所有权转移
变量 a = [1, 2, 3]
变量 b = a      // 所有权从 a 转移到 b
// 打印(a)     // ❌ 错误：a 已失去所有权

// 函数参数转移所有权
函数 处理(data: 拥有 整数[]) {
    打印(长度(data))
}

变量 arr = [1, 2, 3]
处理(arr)        // 所有权移动到函数
// 打印(arr)   // ❌ 错误：arr 已移动
```

### 2.2 借用规则

借用允许在不转移所有权的情况下访问数据：

```cplang
// 不可变借用（多个读者）
x = [1, 2, 3]
a = &x            // 不可变借用
b = &x            // 多个不可变借用允许
打印(a[0])        // → 1
打印(b[1])        // → 2

// 可写借用（唯一写者）
y = [1, 2, 3]
r = &可写 y       // 可写借用（独占）
r[0] = 100        // 通过借用修改
// s = &y         // ❌ 错误：已有可写借用时不能再借
```

### 2.3 借用检查规则总表

| 场景 | 允许？ | 说明 |
|------|--------|------|
| 多个 `&x` | ✅ | 多个不可变引用 |
| `&x` + `&x` | ✅ | 多个读者 |
| `&x` 后 `&可写 x` | ❌ | 已有不可变借用 |
| `&可写 x` 后 `&可写 x` | ❌ | 只能有一个写者 |
| `&可写 x` 后 `&x` | ❌ | 已有可写借用 |
| 借用结束后的 `&可写 x` | ✅ | 借用已释放 |
| 函数返回借用 | ⚠️ | 需显式标注生命周期 |

### 2.4 借用生命周期

```cplang
// 借用在作用域结束时自动释放
变量 data = [1, 2, 3]
{
    r = &data           // 借用开始
    打印(r[0])          // 使用借用
}                       // 借用结束
// 现在可以安全地可写借用了
w = &可写 data          // ✅
```

## 3. 生命周期标注

当函数返回借用引用时，需要生命周期标注：

```cplang
// 获取数组第一个元素的借用
函数 首个(arr: 借用 整数[]): 借用 整数 {
    返回 &arr[0]
}

// 生命周期参数：显式标注引用关系
函数 最長<'a>(a: 借用 字符串<'a>, b: 借用 字符串<'a>): 借用 字符串<'a> {
    如果 (长度(a) >= 长度(b)) { 返回 a }
    返回 b
}
```

### 生命周期省略规则

```cplang
// 省略规则 1：每个参数有自己的生命周期
函数 获取(arr: 借用 整数[]): 借用 整数  // 输出生命周期同输入

// 省略规则 2：只有一个输入生命周期时，输出复用
函数 第一(s: 借用 字符串): 借用 字符  // → 'a

// 省略规则 3：多个参数需要显式标注
函数 选择<'a>(a: 借用 字符串<'a>, b: 借用 字符串<'a>): 借用 字符串<'a>
```

## 4. 共享所有权

使用 `共享` 关键字创建引用计数共享所有权：

```cplang
// 共享所有权（类似 C++ shared_ptr）
变量 data: 共享 整数[] = 共享([1, 2, 3])

函数 处理数据(d: 共享 整数[]) {
    打印(长度(d))
}

// 多个函数可以共享数据的所有权
处理数据(data)
// 这里 data 仍然可用
```

### 所有权模式对比

| 模式 | 关键字 | 所有权 | 性能开销 | 适用场景 |
|------|--------|-------|---------|---------|
| GC 默认 | 无 | 共享 (GC) | GC 暂停 | 通用场景 |
| 独占 | `拥有` | 单一所有权 | 无 | 大对象/缓冲区 |
| 借用 | `借用` | 零开销引用 | 无 | 临时访问 |
| 共享 | `共享` | 引用计数 | 原子操作 | 多消费者 |

## 5. 可信块（绕过安全检查）

在确定安全的情况下，可以使用 `信任` (trust) 块绕过借用检查：

```cplang
// 需要同时借用同一结构的多个字段
变量 point = {x: 10, y: 20}

信任 {
    a = &可写 point.x
    b = &point.y            // 可信块内允许
    // 因为 x 和 y 是同一结构体的不同字段，没有数据竞争
}
```

### 使用准则

```cplang
信任 {
    // ✅ 可以：不同字段的借用
    a = &可写 struct.field1
    b = &struct.field2

    // ❌ 危险：同一数据的读写
    c = &可写 data
    d = &data               // 可能导致悬挂指针
}
```

## 6. 不安全块（手动内存管理）

在需要极致性能或与 C 交互时，使用 `不安全` 块：

```cplang
不安全 {
    // 直接指针操作
    变量 ptr = 分配(1024)         // 分配未初始化内存
    变量 buf = 字节[1024]          // 分配零初始化内存
    
    // 与 C 接口交互
    变量 raw = 转换指针(c_func())
    
    // 手动管理
    延迟 释放(ptr)                // defer：作用域结束时释放
}
```

### defer 语句

`推迟` (defer) 确保资源在作用域结束时释放：

```cplang
函数 读取文件(路径: 字符串): 字符串 {
    变量 f = 打开文件(路径)
    推迟 关闭文件(f)              // 无论是否出错，都会执行
    
    变量 content = 读取所有(f)
    返回 content                  // 返回前执行 defer
}
```

## 7. 常见模式

### 7.1 使用所有权避免不必要的复制

```cplang
// ❌ 低效：复制大数组
函数 处理(data: 整数[]) {     // 按值传递，复制整个数组
    打印(长度(data))
}

// ✅ 高效：借用
函数 处理(data: 借用 整数[]) {  // 按引用传递，零开销
    打印(长度(data))
}

// ✅ 转移所有权
函数 消费(data: 拥有 整数[]) {   // 所有权移动，无复制
    // 处理 data
}                               // 作用域结束时 data 释放
```

### 7.2 迭代器借用

```cplang
// 遍历时借用元素
函数 打印所有(arr: 借用 整数[]) {
    遍历 (x : arr) {             // x 是借用引用
        打印(x)
    }
}

// 可变迭代
函数 加倍(arr: 可写 借用 整数[]) {
    遍历 (x : arr) {
        x = x * 2               // 通过可写借用修改
    }
}
```

### 7.3 结构体中的所有权

```cplang
类 缓冲区 {
    变量 data: 拥有 字节[]       // 字段拥有数据所有权
    变量 大小: 整数
    
    函数 新建(cap: 整数): 缓冲区 {
        返回 缓冲区 {           // 结构体字面量
            data: 拥有 字节[cap],
            大小: cap
        }
    }
}

// 方法借用 self
函数 获取数据(self: 借用 缓冲区): 借用 字节[] {
    返回 &self.data
}
```

## 8. 与 Rust 所有权对比

| 特性 | CP | Rust |
|------|----|------|
| 默认内存管理 | GC | 静态所有权 |
| 借用检查 | ✅ 可选 | ✅ 强制 |
| `&T` | ✅ `&x` | ✅ `&T` |
| `&mut T` | ✅ `&可写 x` | ✅ `&mut T` |
| 生命周期 | ✅ 显式标注 | ✅ 显式标注 |
| `Box<T>` | ✅ `拥有` | ✅ `Box<T>` |
| `Rc<T>` | ✅ `共享` | ✅ `Rc<T>` |
| 不安全块 | ✅ `不安全` | ✅ `unsafe` |
| 学习曲线 | 平缓（渐进） | 陡峭（强制） |

## 9. 最佳实践

### 9.1 选择何种内存管理模式

| 场景 | 推荐模式 | 原因 |
|------|---------|------|
| 脚本/原型 | L1: GC | 开发快，无需操心内存 |
| Web 应用 | L1: GC | 性能足够，安全优先 |
| 游戏逻辑 | L2: 所有权 | 实时性能要求 |
| 系统工具 | L2: 所有权 | 资源控制 |
| 嵌入式 | L3: 手动 | 无 GC 运行时 |
| C 互操作 | L3: 不安全 | 需要直接操作指针 |

### 9.2 所有权检查的编译期开销

所有权检查在**编译时**完成，不会影响运行时性能：

```cplang
// 编译时检查：
// r = &可写 data  → 检查是否有其他借用活跃
// data.modify()   → 检查没有活跃借用

// 零运行时开销：检查通过后生成与 C 相同效率的代码
```

### 9.3 迁移路径

```
初学者
  │
  ▼ 掌握基础语法
L1: GC 模式（全动态类型）
  │
  ▼ 遇到性能瓶颈
L2: 所有权 + 借用（关键路径加类型标注）
  │
  ▼ 极致优化需求
L3: 不安全块 + 手动（性能热点）
```
