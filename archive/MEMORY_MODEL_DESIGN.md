# 内存管理设计决策

## 决策：双模式设计（默认 GC + 可选控制）

**日期**：2026-04-21

### 核心原则

```
默认安全（GC），可选控制（所有权/手动）
```

这与 Rust 的"全员强制所有权"不同，更接近 C#/Go 的设计哲学。

### 三层心智模型

| Level | 适用人群 | 内存模式 | 学习成本 |
|-------|---------|---------|---------|
| 1 | 初学者 | GC 自动管理 | 低 |
| 2 | 进阶用户 | 所有权系统 | 中 |
| 3 | 系统程序员 | unsafe + 手动 | 高 |

### 关键词设计

```cplang
// GC 模式（默认）
变量 数据 = 字节[1024]        // GC 管理

// 所有权模式
函数 处理(数据: 拥有 字节[])  // 独占所有权，类似 unique_ptr
函数 查看(数据: 借用 字节[])  // 借用引用，类似 &T
函数 共享(数据: 共享 字节[])  // 共享所有权，类似 shared_ptr

// 手动模式
不安全 块 {
    变量 指针 = 分配内存(1024)
    延迟 释放内存(指针)       // defer 语法
}
```

### 不引入 C++ 智能指针语法

原因：
1. 语法复杂（shared_ptr<T>, unique_ptr<T>, weak_ptr<T>）
2. 概念混淆（所有权 vs 引用计数）
3. 运行时开销（原子操作）

替代方案：用语义清晰的关键词（拥有/借用/共享）

### 与其他语言对比

| 语言 | 默认模式 | 可选控制 | 学习曲线 |
|------|---------|---------|---------|
| C++ | 手动 | 智能指针 | 陡峭 |
| Rust | 所有权 | unsafe | 陡峭 |
| Go | GC | 无 | 平缓 |
| C# | GC | unsafe | 平缓 |
| **CP** | GC | 所有权 + unsafe | 渐进 |

### 决策依据

1. **易用性优先** — 中文编程语言的目标用户包括初学者
2. **渐进学习** — 不需要一开始就理解所有权
3. **性能可控** — 高级用户可以获得 C++ 级别的控制力
4. **避免陷阱** — 不引入智能指针的复杂性

## 附录：语法设计草案

### 所有权语法

```cplang
// 独占所有权（类似 unique_ptr）
类型 缓冲区 {
    拥有 变量 数据: 字节[]
    
    构造(大小: 整数) {
        自身.数据 = 字节[大小]
    }
    
    // 析构自动调用
    析构 {
        打印("缓冲区释放")
    }
}

// 所有权转移
函数 消费(缓冲: 拥有 缓冲区) {
    // 缓冲在此函数结束后释放
}

函数 测试() {
    变量 buf = 缓冲区(1024)
    消费(移动 buf)      // 所有权转移
    // buf 不能再使用
}
```

### 借用语法

```cplang
// 借用（类似 &T）
函数 读取(数据: 借用 字节[]) -> 整数 {
    返回 数据.长度
}

函数 测试() {
    变量 buf = 字节[1024]
    变量 长度 = 读取(buf)    // 自动借用
    // buf 仍然有效
}
```

### 共享语法

```cplang
// 共享所有权（类似 shared_ptr）
函数 共享示例() {
    变量 数据 = 共享 字节[1024]
    
    变量 引用1 = 数据        // 引用计数 +1
    变量 引用2 = 数据        // 引用计数 +1
    
    // 所有人都离开作用域后自动释放
}
```

### 手动模式

```cplang
// unsafe 块
不安全 块 {
    变量 指针: *字节 = 标准库.分配(1024)
    
    延迟 标准库.释放(指针)
    
    // 指针运算
    指针 = 指针 + 100
    @指针 = 42               // 写入
    变量 值 = @指针          // 读取
}
```
