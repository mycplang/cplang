# CP 语言功能参考

## 语法速查

### 变量
```
x = 10                    // 隐式声明
变量 y = 20               // 显式声明
变量 z: 整数 = 30         // 带类型标注
```

### 运算符
```
+  -  *  /  %             // 算术
==  !=  <  >  <=  >=      // 比较
&&  ||  !                 // 逻辑
```

### 控制流
```
如果 (条件) { ... }
否则 如果 (条件) { ... }
否则 { ... }

当 (条件) { ... }         // while 循环
循环 (变量 i=0; i<10; i=i+1) { ... }  // for 循环
继续                      // continue
跳出                      // break
```

### 函数
```
函数 名(参数): 返回类型 {
    ...
    返回 值
}
```

### 数组
```
arr = [1, 2, 3]
arr[0]                    // 访问
长度(arr)                 // 长度
push(arr, 4)             // 追加
```

### 表（字典）
```
t = {}
表设(t, "键", "值")
表取(t, "键")
表有(t, "键")            // 是否存在
```

## 渐进类型系统

CP 语言默认是动态类型，但可以**渐进地**添加类型标注来获得**接近 C++ 的性能**。

### 类型推断
```
x = 10        // 自动推断为 整数
y = 3.14      // 自动推断为 浮点
s = "hello"   // 自动推断为 字符串
```

### 显式类型（直接 JIT 编译！）
```
函数 累加(n: 整数): 整数 {
    变量 s: 整数 = 0    // 显式标注
    变量 i: 整数 = 0
    当 (i < n) {
        s = s + i       // 使用 typed 指令 (OP_IADD)
        i = i + 1
    }
    返回 s
}
```
带类型标注的函数会**跳过字节码解释器，直接 JIT 编译为机器码**，性能提升 65-95 倍。

### 中文类型名
```
整数    int
浮点    float
布尔    bool
字符串  string
字符    char
空      void
```

## JIT 编译器

### 使用方式
```bash
# 热点 JIT（推荐）：函数调用超过阈值自动编译
./cplang -c --hotspot --hotspot-threshold=100 程序.cp

# 全量 JIT：预编译所有函数
./cplang -j 程序.cp
```

### 性能数据
| 场景 | 字节码 | JIT | 加速 |
|------|--------|-----|------|
| 1 亿次循环 | 超时 | 0.35s | 100x+ |
| 1000 万次调用 | 5.4s | 0.057s | 95x |
| typed 函数调用 | 6.8s | 0.10s | 65x |

## 内存管理

CP 语言使用**三色标记-清除垃圾回收 (GC)** 自动管理内存，无需手动分配或释放。

```cp
// 创建对象，GC 自动回收
变量 数据 = [1, 2, 3, 4, 5];  // 数组由 GC 管理
变量 信息 = 表创建(["名字", "年龄"], ["小明", 12]);
// 无需手动释放，GC 在内存达到阈值时自动运行
```

## 内置函数

### 输出
| 函数 | 说明 |
|------|------|
| `打印(x)` | 输出值 |
| `println(x)` | 输出并换行 |

### 类型
| 函数 | 说明 |
|------|------|

| 函数 | 说明 |
