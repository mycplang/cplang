### 1. Bool 类型输出修复

**问题描述**：
```cplang
变量 x = 真;
打印(x);  // 输出: <1> 而非 true
```

**根因分析**：
经过深入调试，发现问题出在 `tests/codegen_e2e_test.cpp` 中的 `printVal` 函数。

测试程序有自己的 `printVal` 函数实现（第52-56行），用于打印原生函数调用的结果。这个实现只处理了整数（tag=2）、浮点数（tag=3）和字符串（tag=4），但没有处理 Bool 类型（tag=1）。

**修复方案**：
在 `tests/codegen_e2e_test.cpp` 的 `printVal` 函数中添加 Bool 类型处理：
```cpp
static void printVal(const Value& v) {
    if (v.tag == 1) { std::cout << (v.i ? "true" : "false"); return; }  // T_BOOL
    if (v.tag == 2) { std::cout << v.asInt(); return; }
    if (v.tag == 3) { std::cout << v.asFloat(); return; }
    if (v.tag == 4 && v.asString()) { std::cout << v.asString()->data; return; }
    std::cout << "<" << (int)v.tag << ">";
}
```

**验证结果**：
```cplang
变量 x = 真;
变量 y = 假;
打印(x);  // 输出: true
打印(y);  // 输出: false
打印(1 == 1);  // 输出: true
打印(1 == 2);  // 输出: false
```
