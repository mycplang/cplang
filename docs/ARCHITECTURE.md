## 组件详解

### 1. 词法分析器 (Lexer)

```
输入: "函数 main() { 打印(1+2); }"
输出: Token序列: [函数, main, (, ), {, 打印, (, 1, +, 2, ), ;, }]
```

| 特性 | 说明 |
|------|------|
| 编码 | 纯 UTF-8（不依赖 wchar_t） |
| 关键字 | 中文 + 英文双关键字系统 |
| 字符串 | 双引号字符串，支持转义序列 |
| 数字 | 十进制、十六进制 (`0x`)、二进制 (`0b`)、八进制 (`0o`) |
| 注释 | `//` 行注释、`/* */` 块注释 |
| 错误 | 全汉化错误消息 (`"第X行: 消息"`) |

### 2. 语法分析器 (Parser)

```
输入: Token序列
输出: AST (抽象语法树)
```

- **递归下降**分析器
- 支持中文/英文关键字混合使用
- 支持运算符优先级和结合性
- 自动多行输入检测（用于 REPL）
- 错误恢复：报告错误后继续解析

### 3. 语义分析器 (Semantic Analyzer)

```
输入: AST
输出: 带类型和符号信息的 AST
检查: 类型错误、重复定义、未定义引用、所有权规则
```

**三阶段分析**：

| 阶段 | 说明 |
|------|------|
| 符号收集 | 遍历 AST 收集所有函数/变量/类型声明 |
| 类型检查 | 验证类型标注的一致性 |
| 类型推断 | 推断未标注变量的类型 |

### 4. 代码生成器 (Codegen)

#### 4.1 字节码生成

生成 16 字节对齐指令，格式：

```
[op][0][a][b][c][imm32][padding(4)]
```

支持两种指令类型：

| 指令类型 | 说明 |
|---------|------|
| 通用指令 | `OP_ADD`, `OP_SUB`, `OP_CALL` — 运行时类型分发 |
| 类型化指令 | `OP_IADD`, `OP_FADD`, `OP_ICMP` — 直接 JIT 编译 |

#### 4.2 LLVM IR 生成

通过 `llvm_codegen.cpp` 生成 LLVM IR：

```llvm
define i64 @斐波那契(i64 %n) {
entry:
  %cmp = icmp slt i64 %n, 2
  br i1 %cmp, label %return, label %recurse

return:
  ret i64 %n

recurse:
  %n1 = sub i64 %n, 1
  %r1 = call i64 @斐波那契(i64 %n1)
  %n2 = sub i64 %n, 2
  %r2 = call i64 @斐波那契(i64 %n2)
  %sum = add i64 %r1, %r2
  ret i64 %sum
}
```

### 5. 值系统 (NaN-Boxing)

所有 CP 值使用 64 位 NaN-boxing 表示：

```
┌────────────────────────────────────────────────────────┐
│  IEEE 754 双精度浮点 NaN-boxing 值编码                  │
├─────────┬───────┬──────────────────────────────────────┤
│ 63(符号) │ 52-62 │ 0-51 (尾数)                         │
│         │ (指数) │                                      │
├─────────┼───────┼──────────────────────────────────────┤
│  0      │ 非全1 │ 浮点数值                              │
│ 任意    │ 全1   │ NaN: 编码非浮点类型                    │
│  ×       │ 0x7FF │ QNaN → 编码为标记值                  │
│  ×       │ 0x7FF │ SNaN → 编码为引用类型指针            │
└─────────┴───────┴──────────────────────────────────────┘
```

| 编码 | 类型 | 说明 |
|------|------|------|
| `0x0000...0000` | Nil | 全零 |
| `0xFFF0...0001` | Bool(f) | LSB=1 |
| `0xFFF0...0003` | Bool(t) | LSB=1, bit1=1 |
| `0xFFFF0000xxxx` | Int | 高位全1，低32位存值 |
| NaN-pointer | String | 指针指向 VMString |
| NaN-pointer | Array | 指针指向 VMArray |
| NaN-pointer | Table | 指针指向 VMTable |
| NaN-pointer | Closure | 指针指向 VMClosure |

### 6. 运行时系统

#### 6.1 虚拟机 (VM)

- **栈式架构**：虚拟机使用值栈执行
- **Threaded-code**：高效指令分发
- **256 个寄存器**：局部变量寄存器分配
- **65536 栈深度**：最大调用深度

#### 6.2 垃圾回收 (GC)

- **三色标记-清除**算法
- **增量式**：分步骤执行
- **自动触发**：分配超过 1MB 阈值
- **手动调用**：支持程序触发 GC
- **循环引用处理**：使用双向可达性分析

### 7. JIT 编译系统

详见 [JIT_GUIDE.md](JIT_GUIDE.md)

### 8. 模块系统

```
导入 "模块名"
```

- **搜索路径**：
  1. 源文件所在目录
  2. 当前工作目录
  3. `packages/` 注册表
  4. `~/.cpkg/packages/` 安装目录
  5. URL 远程导入（支持 `https://`）
- **远程导入**：通过 `URLDownloadToFile` (Windows) 或 `curl` (Unix) 下载
- **模块缓存**：已导入模块不重复加载

## 数据流

```
源码 (.cp)
  │
  ▼ [Lexer]
Token 流
  │
  ▼ [Parser]
AST (Program → Stmt[] → Expr[])
  │
  ▼ [SemanticAnalyzer]
带符号信息的 AST
  │
  ├──▶ [Codegen] ──▶ 字节码 ──▶ [BytecodeOptimizer] ──▶ [VM] ──▶ 输出
  │
  └──▶ [LLVMCodegen] ──▶ LLVM IR ──▶ [ORC JIT] ──▶ 机器码 ──▶ 输出
                                    │
                                    └──▶ [AOTCompiler] ──▶ 可执行文件
```

## 构建系统

```
项目结构:
cplang/
├── include/          # 头文件
│   ├── ast/         # AST 节点定义
│   ├── codegen/     # 代码生成器
│   ├── core/        # 核心类型 (Value, String)
│   ├── jit/         # JIT 接口
│   ├── lexer/       # 词法分析器
│   ├── parser/      # 语法分析器
│   ├── repl/        # REPL
│   ├── semantic/    # 语义分析器
│   ├── stdlib/      # 标准库
│   └── vm/          # 虚拟机 (Value, VM, GC)
├── src/              # 实现文件
├── tests/            # 测试用例
├── tools/            # 工具 (VSCode插件, LSP)
├── docs/             # 文档
└── third_party/      # 第三方依赖
```

**构建方式**：

```bash
# Windows (MSVC)
cd build_cmake_new
cmake .. -G "Visual Studio 17 2022"
cmake --build . --config Release

# Linux (GCC/Clang)
mkdir build && cd build
cmake ..
make -j$(nproc)
```

## 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 值表示 | NaN-boxing | 无开销类型标签，64位对齐 |
| 内存管理 | 默认 GC + 可选所有权 | 降低入门门槛 |
| 编码 | 纯 UTF-8 | 跨平台一致性 |
| JIT | LLVM ORC v2 | 行业标准，持续优化 |
| 字节码 | 16字节指令 | 对齐优化，简化解码 |
| 关键字 | 中文 + 英文别名 | 降低中文用户入门门槛 |
| 编译策略 | 先字节码，热点 JIT | 快速启动 + 热点加速 |
