# CP 语言 v0.5.0 发布说明

## 概述

CP语言 v0.5.0 — "框架与生态"大版本。新增 HTTP 路由框架、ORM 模块，泛型+Trait 语义检查增强。

## 🆕 全新模块

### HTTP 路由框架 (`@cp/http`)
| API | 说明 |
|-----|------|
| `路由.创建()` | 创建路由器实例 |
| `路由.注册(方法, 路径, 处理器)` | 注册路由处理器 |
| `路由.中间件(处理器)` | 添加中间件 |
| `路由.启动(端口)` | 启动 HTTP 服务 |
| `路由.静态文件(端口, 目录)` | 启动静态文件服务 |
| `请求.方法 / 路径 / 查询 / 请求体` | 请求对象 |
| `响应.状态码 / JSON / 文本 / 标头` | 响应对象 |

### ORM 框架 (`@cp/orm`)
| API | 说明 |
|-----|------|
| `模型.定义(表名, 字段, 选项)` | 定义数据模型（自动建表） |
| `模型.创建(表名, 数据)` | 插入记录 |
| `模型.查询(表名).where().排序().限制().全部()` | 查询构建器 |
| `模型.查询(表名).首个() / .计数()` | 快捷查询 |
| `模型.更新(表名, 数据).where().执行()` | 更新记录 |
| `模型.删除(表名).where().执行()` | 删除记录 |
| `模型.迁移(表名, 新字段)` | 表结构迁移 |
| `模型.列出表()` | 列出所有表 |

## 🔧 语言特性

- 🔧 **泛型约束检查**: semantic_analyzer 新增 trait bound 强制检查
- 🔧 **版本号**: 编译器主版本升级至 0.5.0

## 修复与改进

- 🔧 AOT 相关代码和文档彻底清理（改用 SFX 打包）
- 🔧 文档架构图更新：添加 HybridJIT 路径，移除 AOT 残留

## 函数总量

- v0.4.0: 875+
- v0.5.0: 900+

## 编译方式

```bash
# 使用 VS 2022 Developer Command Prompt
build_v04.bat Release
```

## 已知限制

- HTTP 路由框架为纯 CP 语言模块，路由匹配基于简单字符串模式
- ORM 框架目前仅支持 SQLite
- 泛型约束检查为编译时静态检查，不支持运行时多态
