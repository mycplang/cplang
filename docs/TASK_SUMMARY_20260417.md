### 1. Foreach 循环修复

**问题描述**:
```cplang
变量 arr = [10, 20];
遍历 (x : arr) {
    打印(x);
}
```
输出无限个 `10`，无法正确遍历数组。

**根因分析**:
在 `compileForEach` 函数中，使用 `emit(OP_LOADINT, oneReg, 1, 0)` 加载立即数 1 到临时寄存器。但 `emit` 函数将值存储在字节 3 的 `b` 字段，而 VM 的 `OP_LOADINT` handler 期望立即数在字节 4-7（使用 `emitInt` 格式）。

这导致立即数 1 未被正确读取，索引始终为 0，循环无法递增。

**修复方案**:
将 `emit(OP_LOADINT, oneReg, 1, 0)` 改为 `emitInt(OP_LOADINT, oneReg, 1)`。

**修改文件**:
- `src/codegen/codegen.cpp` 第 432 行

**验证结果**:
```
输入: 变量 arr = [10, 20]; 遍历 (x : arr) { 打印(x); }
输出: 10  20
状态: ✅ 正确遍历并退出循环
```

## 📊 架构改进

### 字节码指令格式
- **统一格式**: 16字节对齐 `[op][0][a][b][c][imm32][padding4]`
- **三种生成方式**:
  - `emit(op, a, b, c)` - 用于寄存器操作指令
  - `emitInt(op, a, imm)` - 用于立即数加载指令
  - `emitJump(op, offset)` - 用于跳转指令
