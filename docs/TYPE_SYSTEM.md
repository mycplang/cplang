# CP 语言类型系统

> **渐进类型**：从动态类型起步，逐步添加类型标注获得接近 C++ 的性能。

## 设计哲学

CP 语言的类型系统采用**渐进类型 (Gradual Typing)** 设计：

```
没有类型标注 → 动态类型（由 VM 在运行时检查）
有类型标注   → 静态类型（编译时检查，生成 typed 指令）
所有类型标注 → 全静态类型（跳过字节码 VM，直接 JIT 编译为机器码）
```

这允许初学者先写动态代码，随着经验增长逐步添加类型。

## 2. 类型标注语法

### 2.1 变量类型标注

```cplang
// 隐式类型（动态推断）
x = 42
name = "小明"

// 显式类型标注
变量 a: 整数 = 10
变量 b: 浮点 = 3.14
变量 c: 字符串 = "你好"
变量 d: 布尔 = 真
变量 e: i32 = 100
变量 f: f64 = 2.718
```

### 2.2 函数参数和返回类型

```cplang
// 无类型标注（动态）
函数 添加(a, b) {
    返回 a + b
}

// 有类型标注（静态类型检查 + typed 指令）
函数 添加(a: 整数, b: 整数): 整数 {
    返回 a + b
}

// 无返回值
函数 日志(msg: 字符串): 空 {
    打印(msg)
}
```

### 2.3 数组类型

```cplang
// 隐式类型数组
arr = [1, 2, 3]

// 显式类型数组（所有元素必须同类型）
变量 nums: 整数[] = [1, 2, 3, 4, 5]
变量 names: 字符串[] = ["小明", "小红", "小刚"]
```

## 3. 类型推断

CP 编译器使用**局部类型推断**（基于 Hindley-Milner 的简化版本）：

```cplang
x = 42          // → x 推断为 整数
y = 3.14        // → y 推断为 浮点
s = "hello"     // → s 推断为 字符串
b = 真          // → b 推断为 布尔

// 表达式类型传播
z = x + 10      // → z 推断为 整数（因为 x 是整数）
w = y * 2.0     // → w 推断为 浮点（因为 y 是浮点）

// 函数返回值推断
函数 平方(n) {
    返回 n * n   // 返回类型由 n 的类型决定
}
```

### 类型推断规则

| 场景 | 推断规则 |
|------|---------|
| 整数 literal `42` | `整数` |
| 浮点 literal `3.14` | `浮点` |
| 字符串 literal `"hi"` | `字符串` |
| 布尔 literal `真` | `布尔` |
| 数组 literal `[1,2,3]` | `整数[]` |
| 二元运算 `a + b` | 操作数类型的共同父类型 |
| 函数返回值 | 由 `返回` 语句类型推断 |
| 三元运算 `a ? b : c` | b 和 c 的共同父类型 |

## 4. 类型转换

### 4.1 隐式转换（允许的）

| 从 | 到 | 说明 |
|----|----|------|
| `i8` | `i16→i32→i64→int` | 整数拓宽，安全 |
| `u8` | `u16→u32→u64→int` | 无符号拓宽，安全 |
| `f32` | `f64→float` | 浮点拓宽，安全 |
| `int` | `float` | 整数到浮点，安全 |
| `i32` | `f64` | 精确转换（32位→53位尾数） |

### 4.2 需要显式转换

```cplang
// 浮点 → 整数（截断）
x = 整数(3.14)     // → 3

// 整数 → 浮点
y = 浮点(42)       // → 42.0

// 字符串 → 整数
n = parseInt("42")  // → 42

// 字符串 → 浮点
f = parseFloat("3.14")  // → 3.14

// 任意值 → 字符串
s = 转字符串(42)    // → "42"
```

### 4.3 不安全的窄化（需要显式标注）

```cplang
// 大整数赋值给窄类型需要显式转换
变量 a: i8 = i8(200)    // 可能丢失数据
变量 b: u32 = u32(-1)   // 负数→无符号
```

## 5. Typed 指令系统

当函数包含完整的类型标注时，代码生成器会生成 **typed 指令**（而非通用指令），直接由 JIT 编译为机器码。

### 5.1 指令对比

| 操作 | 通用指令 (untyped) | 类型化指令 (typed) |
|------|-------------------|-------------------|
| 加法 | `OP_ADD` | `OP_IADD` (整数加) / `OP_FADD` (浮点加) |
| 减法 | `OP_SUB` | `OP_ISUB` / `OP_FSUB` |
| 乘法 | `OP_MUL` | `OP_IMUL` / `OP_FMUL` |
| 除法 | `OP_DIV` | `OP_IDIV` / `OP_FDIV` |
| 比较 | `OP_CMP` | `OP_ICMP` / `OP_FCMP` |
| 加载 | `OP_LOAD` | `OP_ILOAD` / `OP_FLOAD` |
| 存储 | `OP_STORE` | `OP_ISTORE` / `OP_FSTORE` |

### 5.2 性能影响

```cplang
// 动态版本（10x 慢）
函数 loopSum(n) {
    s = 0
    i = 0
    当 (i < n) {
        s = s + i
        i = i + 1
    }
    返回 s
}

// 类型化版本（JIT 直接编译，100x 快）
函数 loopSum(n: 整数): 整数 {
    变量 s: 整数 = 0
    变量 i: 整数 = 0
    当 (i < n) {
        s = s + i       // → OP_IADD
        i = i + 1       // → OP_IADD
    }
    返回 s
}
```

| 场景 | 无类型 | 有类型 + JIT | 加速比 |
|------|--------|-------------|-------|
| 1亿次循环 | 超时 (>60s) | 0.35s | **>170x** |
| 1000万次函数调用 | 5.4s | 0.057s | **95x** |
| 排序 10k 数组 | 1.2s | 0.03s | **40x** |

## 6. 类型安全规则

### 6.1 编译时检查（有类型标注时）

```cplang
// ✅ 正确
变量 a: 整数 = 42

// ❌ 错误：类型不匹配
变量 b: 整数 = "hello"     // 语义错误：不能将字符串赋值给整数

// ❌ 错误：函数返回类型不匹配
函数 获取值(): 整数 {
    返回 "错误"              // 语义错误
}
```

### 6.2 运行时检查（无类型标注时）

即使没有类型标注，VM 在运行时也会进行安全检查：

```cplang
x = "你好"
y = x + 42   // 运行时错误：字符串不能加整数
```

### 6.3 渐进安全性

```
标注程度    编译时检查    运行时检查    性能
─────────  ──────────  ──────────  ─────
无标注       无          完整       1x (基准)
部分标注     部分        完整       1x–50x
全标注       完整        完整       >100x
```

## 8. 类型系统实现细节

### 8.1 NaN-Boxing 值表示

所有 CP 语言的值在内部使用 64 位 **NaN-boxing** 表示：

```
┌──────────────────────────────────────────────────────────────┐
│                     64-bit NaN-Boxing                        │
├──────────────┬───────────────────────────────────────────────┤
│ 63 (符号位)  │   NaN 静默位标记                               │
│ 52-62 (指数) │   0x7FF → NaN (标记为引用类型)                  │
│             │   其他 → 浮点数值本身                           │
│ 0-51 (尾数)  │   引用类型：堆指针 (48位地址空间)               │
│             │   整数：int64 值                                 │
└──────────────┴───────────────────────────────────────────────┘
```

- **浮点数**：直接使用 IEEE 754 双精度格式
- **整数**：使用 NaN 区域的尾数位存储（int32 直接装箱）
- **引用类型**：指针存储在 NaN 区域的尾数位
- **布尔值**：使用特殊的 NaN 标记模式
- **nil**：全零表示为空值

### 8.2 类型标签

每种值在 NaN-boxing 中有唯一的位模式标记：

| 类型 | 标记位模式 | 说明 |
|------|-----------|------|
| `Nil` | `0x0000_0000_0000_0000` | 全零 |
| `Bool` | `0xFFFx_xxxx_xxxx_xxx1` | LSB=1 |
| `Int` | `0xFFFF_0000_0000_00xx` | 高位全1，低字节存值 |
| `Float` | 标准 IEEE 754 | 直接使用 |
| `String` | NaN-boxed 指针 | 标记为引用类型 |
| `Array` | NaN-boxed 指针 | 标记为引用类型 |
| `Table` | NaN-boxed 指针 | 标记为引用类型 |
| `Closure` | NaN-boxed 指针 | 标记为引用类型 |
| `CFunction` | NaN-boxed 指针 | 标记为引用类型 |

## 9. 最佳实践

### 9.1 推荐的类型使用策略

```cplang
// 1️⃣ 原型阶段：只用动态类型
函数 计算折扣(价格, 折扣率) {
    返回 价格 * (1 - 折扣率)
}

// 2️⃣ 稳定后添加类型标注
函数 计算折扣(价格: 浮点, 折扣率: 浮点): 浮点 {
    返回 价格 * (1 - 折扣率)
}

// 3️⃣ 关键性能路径：全类型 + 内联
函数 距离(x1: 浮点, y1: 浮点, x2: 浮点, y2: 浮点): 浮点 {
    变量 dx: 浮点 = x2 - x1
    变量 dy: 浮点 = y2 - y1
    返回 平方根(dx * dx + dy * dy)
}
```

### 9.2 何时使用显式类型

| 场景 | 推荐 | 原因 |
|------|------|------|
| 快速原型 | 无类型 | 开发速度快 |
| 小程序 (<100行) | 无类型 | 足够使用 |
| 中等程序 (100-1000行) | 关键函数标注 | 平衡性能和可读性 |
| 大型程序 (>1000行) | 全标注 | 编译时检查 + JIT |
| 库/模块公开 API | 全标注 | 文档化 + 类型安全 |
| 计算密集循环 | 全标注 | JIT 编译加速 |
