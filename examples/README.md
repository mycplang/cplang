# 📚 CP 语言示例 — 纯中文 API 版

## 简介

本目录包含 CP 语言的所有示例程序，**全部使用中文 API 编写**。

CP 语言支持完整的原生中文语法：中文变量名、中文函数名、中文关键字。
所有标准库函数都有对应的中文别名，可以完全用中文进行编程。

## 中文编程入门

CP 语言支持以下中文特性：

### 关键字
```
变量  函数  如果  否则  当  返回  真  假  继续  跳出  导入  包
```

### 变量
```cp
变量 用户名 = "张三";
变量 年龄 = 25;
变量 成绩表 = [98, 87, 92];
变量 学生信息 = {姓名: "李四", 年龄: 19};
```

### 函数
```cp
函数 计算平均(数组) {
    变量 总和 = 0;
    变量 i = 0;
    当 (i < 表长(数组)) {
        总和 = 总和 + 数组[i];
        i = i + 1;
    }
    返回 总和 / 表长(数组);
}
```

### 字符串
```cp
变量 问候 = "你好" + "世界";
打印(长度(问候));         // 4
打印(子串(问候, 0, 2));  // "你好"
打印(包含(问候, "世界")); // 真
```

### 表（字典）
```cp
变量 书 = 表创建(["书名", "作者"], ["三体", "刘慈欣"]);
打印(表取(书, "书名"));   // "三体"
表设(书, "年份", 2008);
打印(表键(书));           // ["书名", "作者", "年份"]
```

### 数组
```cp
变量 列表 = [1, 2, 3];
追加(列表, 4);
插入(列表, 0, 0);
弹出(列表);
打印(表长(列表));
```
