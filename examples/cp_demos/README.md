# CP语言 示例程序集

本目录包含 10 个 CP语言 (.cp) 示例程序，覆盖语言的主要特性。

## 示例列表

| # | 文件 | 内容 |
|---|------|------|
| 1 | `01_hello.cp` | Hello World、字符串拼接 |
| 2 | `02_types_ops.cp` | 整数/浮点/布尔/字符串类型与运算符 |
| 3 | `03_condition.cp` | if/else if/else 条件判断、成绩评定 |
| 4 | `04_loop.cp` | while 循环、数组创建与遍历 |
| 5 | `05_function.cp` | 函数定义、递归阶乘与斐波那契 |
| 6 | `06_array.cp` | 数组求和、最大值、元素修改 |
| 7 | `07_struct.cp` | 结构体声明、创建、字段访问 |
| 8 | `08_table.cp` | 匿名表（键值对）创建与读写 |
| 9 | `09_foreach.cp` | for-each 循环、数组筛选与过滤 |
| 10 | `10_grading_system.cp` | 综合：学生成绩管理系统 |

## 运行方式

```bash
# 编译并执行单个示例
cplang -c examples/cp_demos/01_hello.cp

# 批量运行所有示例
for f in examples/cp_demos/*.cp; do cplang -c "$f"; done
```

## 语言特性速览

### 中文关键字
`函数` `变量` `如果` `否则` `当` `循环` `遍历` `结构体` `返回` `打印` `真` `假`

### 默认入口
程序从 `主()` 函数开始执行，自动调用无需显式标记。

### 数组
`[1, 2, 3]` — 支持索引访问 `arr[0]`，动态长度 `长度(arr)`

### 结构体
```cp
结构体 学生 { 姓名; 年龄; }
变量 s = 学生{姓名: "张三", 年龄: 20};
打印(s.姓名);
```

### 匿名表
```cp
变量 表 = {};
表.键 = "值";
打印(表.键);
```
